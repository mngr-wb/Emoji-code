# Emoji Code 改善要件

- 状態: Frozen
- Implementation approval: 2026-09-06（本人が改善案4項目を承認し「行ってください」と明示）

## Problem / Goal / Users

絵文字暗号を作る人と受け取る人が、変換の曖昧さなく、同じ暗号表を簡単に共有・移行できるようにする。

## Requirements

1. 小書きかな、濁点・半濁点、カタカナ、複数文字の特殊変換を往復変換できる。
2. 同じ絵文字が複数文字へ割り当てられる曖昧な設定を保存しない。
3. 暗号文と暗号表をURLフラグメントに含め、受信者が開くと自動で解読する。受信した設定は保存設定を自動上書きしない。
4. 例文、入力消去、結果を逆方向へ渡す操作を用意する。
5. 暗号表をJSONで書き出し・読み込みできる。
6. 暗号表の変更後、表示中の変換結果を更新する。
7. 既存のGitHub Pages URLと静的HTML/CSS/JS構成を維持する。

## Acceptance Criteria

- `node tests/emoji-code.test.mjs` が終了コード0で通る。
- `らくてん`、`きゃっと`、カタカナ、濁点・半濁点、複数文字の特殊変換が往復一致する。
- 重複絵文字設定が拒否される。
- 共有URLの生成と読込で暗号文・暗号表が一致する。
- HTMLから追加操作を実行でき、JavaScript構文検査が通る。

## Out of Scope

- Vercel移行、GitHubへのpush、公開、API・DB・ログイン機能、デザイン全面刷新。

## Decisions and rationale

- 共有データはサーバーへ送られないURLフラグメントへ保存する。
- 小書きかなは対応する絵文字の後ろに `^` を付け、既存暗号との互換性を保つ。
- 設定ファイルと共有データにはversionを持たせ、将来の形式変更を判別可能にする。
